# ADR-001: Firebase Authentication and Firestore Integration Strategy

## Status
Accepted

## Context
Lab 5 requires integrating user authentication, user-specific note management in Firestore, and push notification services using Firebase Cloud Messaging (FCM) into the Flutter project.

## Decision
- We decided to use Firebase Authentication for managing user sessions.
- User-specific note data is structured under the `users/{uid}/notes` subcollection.
- We utilized Firestore Streams to enable real-time UI updates for notes.

## Consequences
- Offline and online states are synchronized seamlessly via Firestore streams.
- Security is enforced using Firestore Security Rules, ensuring users can only read and write their own data.
